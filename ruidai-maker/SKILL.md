# ruidai-maker

数学の元問題をもとに、同じ解法で解ける類題を作る。答えは必ずスクリプトで検算する。

## 入力

- 元問題と、その解答（解き方がわかるもの）。講義ノート全体は不要。

## 類題の作り方（変え方）

ユーザーの指定がなければ「数値替え」にする。

- **数値替え**：係数・定数・区間だけを変える。
- **条件替え**：区間や条件を変える。
- **設定替え**：同じ解法を、別の関数や場面で使う。

## 検算できる型

| 分野 | type |
|---|---|
| 極限・定積分・導関数・方程式 | `limit` `integral` `derivative` `solve` |
| 極値・閉区間の最大最小 | `extrema` `maxmin` |
| 偏微分・重積分 | `partial` `double_integral` |
| 線形代数（行列式・逆行列・固有値・階数） | `matrix` |
| 常微分方程式（一般解・初期値問題） | `ode` |

検算用ファイルの書き方は `references/types.md` にある。**使う型の節だけを読む**（全部は読まない）。
どの型にも当てはまらない問題（証明問題、図形の問題など）は、検算せずに「検算：対象外」と書く。

## 手順

1. **検算の準備を確認する。** `python -c "import sympy"` が成功するか確かめる。
   失敗したら、ユーザーに `python -m pip install --user sympy` を案内する。
   入れられない場合は類題を作ってよいが、すべての類題に「検算：未実施」と書き、答えが誤っている可能性を伝える。
2. 元問題の解法の要点を1行でまとめ、使う型を決める。
3. 指定された数だけ類題を作る（指定がなければ3問）。
4. 検算用ファイル `problems.json` を作業用の一時フォルダに保存する（ユーザーのファイルと混ぜない）。
5. このスキルのフォルダにある `scripts/verify.py` で検算する：
   `python <このスキルのフォルダ>/scripts/verify.py <一時フォルダ>/problems.json`
6. NG・ERROR の問題は直して、もう一度検算する。
7. 出力する。**問題文と答えは、スクリプトが表示したものをそのまま使う**（`$` で囲み直したり、式を書き直したりしない）。
   条件替えなどで前置き（「$a > 0$ とする。」など）が必要なときは、問題文の前に書き足してよい。

## スクリプトの表示

```
[OK] 5
  問題: $f(x) = x^{3} - 3 x$ の極値を求めよ。
  答え: $x = -1$ で極大値 $2$、$x = 1$ で極小値 $-2$
```

## 出力形式

```
### 類題1（数値替え）
**問題**：<スクリプトの「問題」>
**答え**：<スクリプトの「答え」>
**要点**：…（3行以内）
元問題：例題1 ／ 検算：OK
```

- 解説は要点3行まで。詳しい解説はユーザーに頼まれたときだけ書く。
- 類題は教材にない自作の問題なので、必ず「元問題」を書いて区別する。
