# ruidai-v7 動作確認レポート

## 1. 実際の過去問での試行（v6 → v7）

公式の解答例が公開されている過去問（長岡技術科学大学 R8「数学・応用数学」、大問4つ・小問14）で、解答例を作った。
過去問の著作権は大学にあるため、問題文・解答・検算ファイルはリポジトリに載せない（`Documents\編入過去問\` 側で作業した）。

### v6 で試した結果（見つかった問題）

| # | 問題 | 内容 |
|---|---|---|
| K1 | 検算できたのは 14 問中 5 問だけ | 固有ベクトル、$P^{-1}AP$、$A^n$（$n$ を含む）、確率、「〜を示せ」の等式を確かめる型がなかった |
| K2 | 指定された解き方を守っていなかった | 「前問と $\int_0^\infty e^{-x^2}dx$ を用いて求めよ」の小問で、値を直接計算しただけだった。値の検算は OK でも、答案としては不十分 |
| K3 | 根拠を飛ばしていた | 「2回目が赤球の確率」を「対称性より $2/n$」の1行で済ませた。公式の解答例は場合分けして計算している |
| K4 | 解答例の出力形式がない | 小問ごとに「どこまで確かめたか」を伝える方法がなかった |

最終的な答えは、14 問すべて公式の解答例と一致した。問題は「検算できる範囲」と「答案としての書き方」だった。

### v7 で試した結果

| | v6 | v7 |
|---|---|---|
| 検算できた小問 | 5 / 14 | 14 / 14（うち「示せ」の4問は結論のみ） |
| 解き方の指定 | 守っていない小問があった | 小問ごとに書き出し、指定どおりに解く手順にした |
| 検算の状態の表示 | なし | 「OK」「結論のみ」「対象外（要確認）」を小問ごとに表示 |

わざと入れた誤答5問（固有ベクトルの向き違い、固有ベクトルが多すぎる、$A^n$ の符号違い、条件付き確率の取り違え、等式の符号違い）は、すべて NG になった。

## 2. 別の大学での確認（名古屋工業大学 2027年度）

長岡技科大に合わせただけの改良になっていないか、別の大学の過去問でも解答例を作った。

| 小問 | 結果 |
|---|---|
| 固有値と固有ベクトル（3×3、重解あり） | OK（固有ベクトル2本の場合も判定できた） |
| $A = B^2$ となる対称行列 $B$ | OK（$B^2$ と $B^T - B$ を `expr` で確認） |
| 3平面の共通部分が直線になる条件 | OK（`linsys`） |
| 重積分 | OK |
| $\sqrt{\lvert x^2 - 1 \rvert}$ の定積分 | **NG**：答えは正しいが、SymPy が絶対値つきの積分を計算できなかった |
| マクローリン展開（一般項） | **対象外**：型がない |
| 2変数関数の極値 | **対象外**：型がない。原点では判定式が 0 になり、判定法だけでは決まらない |

→ 残った3つは ruidai-v8 の課題にする。

## 3. 自作の例題での確認（リポジトリに載せたもの）

`examples/sample-problems.md` の例題9〜11（自作）で解答例を作った。出力は `kaitou.md`、検算ファイルは `problems.json`。

```
[OK] 9-1   固有値と固有ベクトル
[OK] 9-2   P^{-1}AP
[OK] 9-3   A^n
[OK] 10-1  確率
[OK] 10-2  条件付き確率
[OK] 11    等式（結論のみ）
[NG] neg-11（固有ベクトルが固有値1つ分足りない）
[NG] neg-12（2^n と 2^(n-1) の取り違え）
[NG] neg-13（条件付き確率を同時確率と取り違え）
[NG] neg-14（戻す・戻さないの取り違え）
--- 10 問中 OK 6 問、NG 4 問
```

既存の型も確認した：v3（OK 10・NG 2）、v4（OK 13・NG 4）、v6（OK 6・NG 3）は前回と同じ結果。
`references/types.md` の見本は 26 問すべて OK。

## 残った課題

| # | 課題 | 内容 |
|---|---|---|
| W4 | 級数展開 | マクローリン展開の一般項を確かめる型がない |
| W5 | 2変数関数の極値 | 型がない。判定式が 0 になる点の扱いも必要 |
| W6 | 記号で計算できない積分 | 絶対値つきなど、SymPy が計算しきれない積分は照合できない |
| W7 | 等式の問題文の表示 | `identity` の問題文は、微分を含むと読めない形になる（解答例モードでは問題文を使わないので実害はない） |
| W3 | 文章題の立式 | 前から残っている課題 |
