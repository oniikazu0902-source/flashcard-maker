## 1. 実際の過去問での確認（v7 → v8）

v7 で残った課題（W4〜W6）が見つかった過去問（名古屋工業大学 2027 年度 数学、大問4つ・小問7）で、もう一度解答例を作った。
過去問の著作権は大学にあるため、問題文・解答・検算ファイルはリポジトリに載せない。

| 小問の内容 | v7 | v8 |
|---|---|---|
| マクローリン展開（一般項） | 対象外（型なし） | OK（最初の 10 項を照合） |
| 2変数関数の極値（判定式が 0 になる点あり） | 対象外（型なし） | OK（判定式 0 の点は、近くの値の大小を調べて「極値ではない」と判定） |
| $\sqrt{\lvert x^2 - 1 \rvert}$ の定積分 | NG（SymPy が計算できない） | OK（$x = 1$ で区間を分け、絶対値を外して計算） |
| 重積分 | OK | OK |
| 固有値と固有ベクトル | OK | OK |
| $A = B^2$ となる対称行列 | OK | OK |
| 3平面の共通部分が直線になる条件 | OK | OK |
| **検算できた小問** | **4 / 7** | **7 / 7** |

公式の解答（答えのみ）とも比べ、7 問すべての答えが一致した（固有ベクトルの向きが逆の1か所は、定数倍の違いなのでどちらも正しい）。
公式の解答には途中式がないので、途中式つきの解答例を作るこのスキルが役に立つ。

わざと入れた誤答4問（一般項の符号違い、原点を極大と誤答、積分の符号違い、$B^2 \neq A$ になる $B$）は、すべて NG になった。

## 2. 自作の例題での確認（リポジトリに載せたもの）

`examples/sample-problems.md` の例題12〜14（自作）。検算ファイルは `problems.json`。

```
[OK] 12   マクローリン展開（注意：一般項から作った 11 次未満の係数を照合した）
[OK] 13   2変数の極値（注意：判定式が 0 の点は、近くの値を調べて「極値ではない」とした）
[OK] 14   絶対値を含む定積分
[OK] 15   x^x の定積分（注意：記号で計算できないので数値で照合した）
[NG] neg-15（一般項の符号を忘れた）
[NG] neg-16（原点を極大と誤答）
[NG] neg-17（絶対値を外し忘れた）
[NG] 要確認の例（x^4 + y^4 の原点：判定できない点がある（要確認））
--- 8 問中 OK 4 問、NG 4 問
```

最後の例は、答え（原点で極小値 0）は正しいが、判定式が 0 で、近くを調べても判定できない。
**確かめられないものを OK にしない**ことを確認するために入れた。スキルでは「検算：対象外（要確認）」と書く。

既存の結果も確認した：v3（OK 10・NG 2）、v4（OK 13・NG 4）、v6（OK 6・NG 3）、v7（OK 6・NG 4）、長岡技科大 R8（OK 14・NG 5）は前回と同じ。
`references/types.md` の見本は 28 問すべて OK。

## 確かめ方の限界（正直に表示するもの）

スクリプトは、確かめ方に限界がある場合に「注意」を表示する。

| 型 | 限界 |
|---|---|
| `series` | 最初の有限個の項だけを照合する。一般項の証明ではない |
| `extrema2` | 判定式が 0 の点は、近くの値の大小で判断する。判定できなければ「要確認」 |
| `integral` | 記号で計算できなければ、数値（12 桁以上の一致）で照合する |
| `identity` | 結論の等式だけを確かめる。証明の過程は確かめない |
