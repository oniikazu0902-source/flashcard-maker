# ruidai-v1 動作確認レポート

- 入力：`examples/sample-problems.md`（極限・定積分・極値の3問）
- 生成方法：Claude が ruidai-v1 の `SKILL.md` に従い、各3問・合計9問の類題を作成（変え方の指定なし＝数値替え）
- 出力：`ruidai.md`（類題）、`problems.json`（検算用ファイル）

## 見つかった問題

| # | 問題 | 具体例 | 原因 |
|---|---|---|---|
| R1 | 極値問題の「答え」そのものを検算できていない | 類題3-1〜3-3 は $f'$ と $f' = 0$ の解だけ確認。極大値 16・極小値 −16 などの値と、どちらが極大かの判定は未確認 | スクリプトに極値の型がない |
| R2 | 問題文と検算した式が同じか確かめられない | 問題文（LaTeX）と `problems.json`（Python の式）を別々に手で書いている。食い違っても OK と表示される | 同じ式を2回書く作りになっている |
| R3 | 答えを手で書き直している | スクリプトの結果 `1/4 + exp(2)/4` を、出力では手で `\dfrac{e^2 + 1}{4}` に直している。写し間違いが起きうる | スクリプトが LaTeX を出さない |
| R4 | 極値問題の検算ファイルが長い | 1問につき2件（`f'` と `f'=0`）、計6件書いた。トークンの無駄 | R1 と同じ |
| R5 | ファイルの置き場所があいまい | `python scripts/verify.py problems.json` は、スキルのフォルダで実行する前提。`problems.json` をどこに保存するかも書いていない | 手順にパスの説明がない |
| R6 | Python や SymPy がない環境での動きが決まっていない | SymPy が未インストールだとスクリプトがエラーで止まる（今回の環境でも最初は未インストールだった） | 手順に確認と代わりの対応がない |

## ruidai-v2 での対応方針

- スクリプトに極値の型（`extrema`）を追加し、極大・極小の値と判定まで検算する（R1・R4）
- スクリプトが問題の式と答えを LaTeX で出力し、それを出力に使う。式を書くのは `problems.json` の1回だけにする（R2・R3）
- 実行場所・保存場所と、SymPy がないときの対応を手順に書く（R5・R6）
