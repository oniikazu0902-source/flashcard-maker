# ruidai-v3 動作確認レポート

- 入力：`examples/sample-problems.md`（v1・v2 と同じ）
- 生成方法：Claude が ruidai-v3 の `SKILL.md` に従って作成。v2 と同じ10問に、わざと誤答を入れた2問を加えて検算
- 出力：`ruidai.md`（類題）、`problems.json`（検算用ファイル）

## 検算の結果（抜粋）

```
[OK] 2-1
  問題: $\displaystyle\int_{0}^{1} x e^{2 x} \, dx$ を求めよ。
  答え: $\frac{1 + e^{2}}{4}$
[OK] 3-4（設定替え）
  問題: $f(x) = x^{4} - 4 x^{3}$ の極値を求めよ。
  答え: $x = 3$ で極小値 $-27$（$x = 0$ は極値ではない）
[NG] neg-1（わざと誤答）: 計算結果 1 + exp(2) / 想定 exp(2)
[NG] neg-3（わざと誤答：x=0 を極大とする）: 計算結果 {'max': [], 'min': [[3, -27]], 'none': [[0, 0]]} / ...
--- 12 問中 OK 10 問、NG 2 問
```

類題10問はすべて OK。わざと入れた誤答2問はどちらも NG になった。

## v2 の問題の確認

| v2 の問題 | v3 の結果 |
|---|---|
| S1 $f''(0) = 0$ で正しい答えが NG | 解消。3-4 が OK になり「$x = 0$ は極値ではない」と表示。誤って $x = 0$ を極大とした答え（neg-3）は NG になった |
| S2 問題文が型に合わない | 解消。「の極値を求めよ。」が付いた |
| S3 数式の中に日本語 | 解消。「$x = 3$ で極小値 $-27$」と日本語が数式の外に出た |
| S4 LaTeX が冗長 | 解消。`\sin {2 x}`、`\frac{1 + e^{2}}{4}` になった |

## 残った課題（今後の改善候補）

| # | 課題 | 内容 |
|---|---|---|
| T1 | 編入数学の主要分野に未対応 | 偏微分・重積分・線形代数（行列・固有値）・微分方程式は検算できない。編入試験でよく出る分野なので、型の追加が必要 |
| T2 | 閉区間の最大・最小に未対応 | 「$0 \le x \le 3$ における最大値」のような問題は、端点の値も比べる必要がある |
| T3 | 周期関数の極値に未対応 | $\sin x$ のように $f'(x) = 0$ の解が無限にある関数は ERROR になる |
| T4 | 導関数の答えの形 | SKILL.md の見本（$x^2 \sin x$ の導関数）で、答えが $x(x \cos x + 2 \sin x)$ とくくった形になった。正しいが、教科書の $2x \sin x + x^2 \cos x$ と形が違う |
| T5 | 類題の「質」は確認していない | スクリプトが確かめるのは答えの正しさだけ。元問題と同じ解法で解けるか、難しすぎないかは確認していない |
