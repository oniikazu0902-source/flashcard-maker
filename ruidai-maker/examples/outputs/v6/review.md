# ruidai-v6 動作確認レポート

- 入力：`examples/sample-problems.md` の例題8（連立1次方程式、自作）
- 生成方法：Claude が ruidai-v6 の `SKILL.md` と `references/types.md` に従って作成。
  類題6問に、受験生がよくやる間違いを入れた3問を加えて検算
- 出力：`problems.json`（検算用ファイル）

## 検算の結果

```
[OK] 8-1（数値替え）
  問題: 次の連立1次方程式が解をもたないように定数 $k$ の値を定めよ。 $$ \begin{cases} x - y + z = 1 \\ x + 4 y + k z = 2 \\ 2 x + k y + 4 z = 3 \end{cases} $$
  答え: $k = -4$
[OK] 8-2（条件替え：右辺）
  答え: $k = 2$
[OK] 8-3（設定替え：無数の解と一般解）
  答え: $k = 4$。このとき $(x, y, z) = \left(\frac{7 - 9 a}{6}, \frac{1 - 3 a}{6}, a\right)$（$a$ は任意）
[OK] 8-4（ただ1つの解）
  答え: $k \neq -5,\ 4$
[OK] 8-5（行列式が k によらず 0）
  答え: $k = 3$。このとき $(x, y, z) = \left(a, 1 - 2 a, a\right)$（$a$ は任意）
[OK] 8-6（パラメータなし）
  答え: $(x, y, z) = \left(1, 2, 3\right)$
[NG] neg-8（誤答：候補を両方答える）: 計算結果 {'ふつうの k': 'unique', '特別な k': {'-4': 'none', '3': 'infinite'}} / 想定 ['-4', '3']
[NG] neg-9（誤答：一般解の符号）: … '解の検算': {'方程式を満たす': False, '任意定数': 1, '必要な数': 1}} / 想定 ['4']
[NG] neg-10（誤答：特殊解だけ）: … '解の検算': {'方程式を満たす': True, '任意定数': 0, '必要な数': 1}} / 想定 ['4']
--- 9 問中 OK 6 問、NG 3 問
```

- 類題6問はすべて OK。問題文（連立方程式つき）と答えをスクリプトが作った。
- 誤答3問はすべて NG。NG の理由（$k = 3$ は解が無数、方程式を満たさない、任意定数が足りない）も表示された。
- 行列式が $k$ によらず 0 の問題（8-5）でも、$k = 3$ を見つけられた。

既存の型も確認した：v4 の17問（OK 13・NG 4）、v3 の12問（OK 10・NG 2）、`references/types.md` の見本15問（OK 15）は、いずれも前回と同じ結果。

## 教科書の問題での試行（v5 → v6 の比較）

| | v5（型の組み合わせ） | v6（`linsys` 型） |
|---|---|---|
| 1問の検算ファイル | 5〜6件 | 1件 |
| 答えの $k$ そのものの照合 | できない（AIが判断） | できる |
| 一般解の検算 | できない（手で代入） | できる |
| 問題文 | 手で書いた | スクリプトが作る |
