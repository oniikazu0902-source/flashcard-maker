# flashcard-maker

講義資料・教科書の抜粋・過去問などの教材から、暗記用フラッシュカードを作る Claude 用スキルです。
大学編入試験（数学・英語・物理など）の対策用に作りました。

## できること

- 教材を渡すと、1枚1論点のフラッシュカードを作ります
- 裏面は「簡潔な答え＋1行の補足」
- 教材に書かれていない内容は作りません。全カードに出典（教材の節番号など）が付きます
- 難易度タグ（基本／応用）付き
- 出力形式：Anki用CSV、Markdown表（印刷・NotebookLM向け）、Quizlet用TSV
- 出力の後に「枚数」「カードにしなかった論点」「教材で不明確な点」を報告します

## ファイル構成

```
flashcard-maker/
├── SKILL.md              … スキル本体（Claude が読む指示書）
├── templates/            … 出力形式の見本（anki.csv / markdown.md / quizlet.tsv）
├── examples/
│   ├── sample-input.md   … 動作確認用の教材サンプル（自作の架空の講義ノート）
│   └── outputs/          … 各バージョンで生成したカードと動作確認レポート
├── CHANGELOG.md          … バージョンごとの変更点と理由
└── README.md             … このファイル
```

## 使い方

1. このフォルダを Claude のスキルフォルダ（例：`~/.claude/skills/flashcard-maker/`）に置きます。
   claude.ai で使う場合は、フォルダを zip にして「設定 → 機能 → スキル」からアップロードします。
2. Claude に教材を渡して「この資料からフラッシュカードを作って。Anki用CSVで」のように頼みます。
   形式を言わなければ、Claude が最初に形式を聞きます。
3. 出力を保存して使います。
   - **Anki**：`.csv` で保存し、「ファイル → 読み込む」で選択
   - **Quizlet**：TSVの中身をコピーし、セット作成画面の「インポート」に貼り付け（区切りは「タブ」）
   - **印刷・NotebookLM**：Markdown表をそのまま貼り付け

## 改善の流れ

同じサンプル教材でカードを作り、問題を見つけて直す、を4回繰り返しました。
各バージョンの生成結果とレポートは `examples/outputs/v1〜v4/` にあります。

| 版 | 見つかった主な問題 | 直したこと |
|---|---|---|
| v1 | — | 要件をそのまま書いた最初の版 |
| v2 | `[a, b]` のカンマでCSVが壊れる、`\|x\|` で表が崩れる、補足に教材にない内容 | 形式ごとのエスケープ、Anki専用の見出し、出典、難易度の定義 |
| v3 | 補足に別カードの答え、英語がほぼ全部「応用」、物理の記号の意味が不明、除外した論点が伝わらない | セルフチェック、出力後の報告、科目ごとの注意、難易度の再定義 |
| v4 | 数式が文字だけで読みにくい、表面に別カードの答えが見える | 数式を形式ごとに書き分け（Anki＝MathJax、Markdown＝LaTeX、Quizlet＝特殊文字）。答えが見えないルールを表面にも適用 |

詳しくは [CHANGELOG.md](CHANGELOG.md) を参照してください。

## 動作確認の方法と限界

- カードの生成は、Claude が各バージョンの `SKILL.md` に従って行いました。
- 形式のチェックは、PowerShell で「アプリと同じルールでファイルを読めるか」（CSVの列数、Markdownの縦線の数、TSVのタブの数など）を確かめました。
- Anki・Quizlet への実際の取り込みと、数式の実際の表示はまだ試していません。残った課題は `examples/outputs/v4/review.md` にまとめています。
