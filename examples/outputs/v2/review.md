## 新しく見つかった問題

| # | 問題 | 具体例 | 原因 |
|---|---|---|---|
| C1 | Ankiで `<` がHTMLの命令として読まれるおそれ | 平均値の定理の `a < c < b`。今回は空白があるので表示されるが、`a<b` と詰めると `<b` が太字の命令になり表示が壊れる | `#html:true` にしたのに `<` `>` `&` の書き換えルールがない |
| C2 | カード同士で答えが重複・漏れる | 1枚目の補足「f(a) = f(b) の場合をロルの定理という」が3枚目の答えそのもの。11枚目の補足と12枚目も同じ内容 | 論点を分けたとき、補足と別カードの重なりを確認していない |
| C3 | 英語の難易度がほぼ全部「応用」になった | 英語9枚中7枚が応用。`not A but B` のような基本構文まで応用 | 応用の条件「構文・語法を読み取る」が広すぎる |
| C4 | 記号の意味がカードだけでは分からない | 「m1 v1 + m2 v2 = m1 v1' + m2 v2'」で、v1' が衝突後の速度だとカードに書かれていない（教材にも明記なし） | 記号の扱い（カードに定義を書くか、教材にない場合どうするか）のルールがない |
| C5 | カードにしなかった論点がユーザーに伝わらない | log(1 + x) の展開は「次回扱う」とあり正しく除外したが、そのことを報告していない | 出力後の報告のルールがない |
| C6 | 出力形式を確認せずに作った | 指定がないとき、黙ってMarkdown表で出力する手順 | 「ユーザーの要望に合わせる」という方針が手順に反映されていない |
| C7 | 出力前の見直しがない | C1〜C4 はルールがあれば防げたが、最後に確認する手順がない | 手順にセルフチェックがない |

## v3 での対応方針

C1〜C7 を直す。あわせて、科目ごとの注意点（数学＝条件を省かない、英語＝例文は教材のものだけ、物理＝記号と単位）を整理する。
