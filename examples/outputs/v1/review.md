# v1 動作確認レポート

- 入力：`examples/sample-input.md`（数学・英語・物理）
- 生成方法：Claude が v1 の `SKILL.md` だけを読み、その指示に従ってカードを作成
- 出力：`cards.csv`（Anki用）、`cards.md`（Markdown表）。全16枚

## 機械チェックの結果

CSVを「Ankiと同じCSVのルール」で読み込み、Markdown表は区切り記号 `|` の数を数えた。

```
--- CSV: 3列でない行 ---
行2 : 5列 → 1列目='平均値の定理の内容は？' 2列目='f(x)が[a'
--- Markdown: | の数が見出し(4)と違う行 ---
行5 : 6 個 → | f(x) = |x| は x = 0 で微分可能か？ | ...
```

## 見つかった問題

### A. 出力形式の問題（そのままではアプリに取り込めない）

| # | 問題 | 具体例 | 原因 |
|---|---|---|---|
| A1 | CSVの列がずれる | 平均値の定理のカードが `[a, b]` のカンマで5列に分かれた | 見本 `templates/anki.csv` が引用符 `"` なしで書かれていた |
| A2 | 見出し行がカードとして取り込まれる | `表面,裏面,タグ` が1枚目のカードになる | Ankiは1行目を見出しとして扱わない。Anki専用の見出し（`#columns:` など）を使う必要がある |
| A3 | Markdown表が崩れる | `|x|`（絶対値）の縦線が表の区切りと解釈された | 縦線のエスケープ（`\|`）のルールがない |
| A4 | 科目で絞り込めない | タグが `基本` だけ | タグの付け方が決まっていない |
| A5 | 補足が読みにくい | 答えと補足が全角スペースでつながり、1行に詰まっている | 答えと補足の区切り方が決まっていない |
| A6 | Quizletでは難易度が消える | QuizletのTSVは「用語」「定義」の2列しか取り込めない | 形式ごとの難易度の載せ方が決まっていない |

### B. カードの中身の問題

| # | 問題 | 具体例 | 原因 |
|---|---|---|---|
| B1 | 教材に明記されていない補足が入った | ロルの定理の「f'(c) = 0 となる c が存在する」、sin x の「奇数次の項だけが現れる」は、教材から推測はできるが書かれていない | 「教材外の内容を作らない」が補足にも適用されることが書かれていない |
| B2 | 根拠を確かめられない | どのカードが教材のどこに基づくのか分からない | 出典を書く欄がない |
| B3 | 1枚に複数の論点 | 「弾性衝突・完全非弾性衝突とは？」で2つの用語、「〜するやいなや」で2つの表現＋倒置 | 「1論点」の判断基準がない |
| B4 | 難易度の基準がぶれる | `not A but B` は基本、`It is not until A that B` は応用だが、理由を説明できない | 基本／応用の定義がない |

## v2 での対応方針

A・B すべてを v2 で直す。特に A1〜A3 は「アプリに取り込めない」致命的な問題なので最優先。
