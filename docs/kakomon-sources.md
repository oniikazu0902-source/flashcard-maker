# 高専からの編入試験（筆記）過去問の入手先一覧

調査日：2026年10月28日。大学の公式サイトで公開されているものだけを対象にした。

## このリポジトリでの扱い

- 過去問の**著作権は各大学にある**。このリポジトリ（公開）には過去問の PDF も問題文も入れない。
- 自分の学習用にダウンロードしたものは、リポジトリの外（`Documents\編入過去問\`）に保存している。
  取得元の URL は同じフォルダの `一覧.tsv` に記録した。
- 公開範囲（年度・科目）は毎年変わる。最新の状況は各大学のページで確認すること。
